# Phase 1.5 Parser Enrichment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract order status/type (dropping cancelled orders), raw currency/tax
fields, and UNSPSC product-classification codes from the already-present OC detail
payload, per the design in
`docs/superpowers/specs/2026-07-12-phase1.5-parser-enrichment-design.md`.

**Architecture:** Extend `schema.py` (field-name constants), `models.py` (dataclass
fields), `parser.py` (extraction), and `store.py` (Parquet columns) in that dependency
order per feature group (status/type, currency/tax, product codes). Add a new
`order_status.py` module (mirroring `municipal.py`) that filters cancelled orders as a
separate pipeline step, wired into `ingest.py`. No new dependencies, no network calls.

**Tech Stack:** Python 3.11+, dataclasses, Polars, pytest, ruff. No new libraries.

## Global Constraints

- Every new field must be verified against the real fixture
  `tests/fixtures/oc_detail_sample.json` before being added to `schema.py` — every task
  below cites the exact fixture line/value already confirmed.
- `schema.py` is the single source of Mercado Público field-name string literals;
  nothing else may hard-code these strings.
- TDD: write the failing test first, run it, confirm the failure reason, implement,
  run again, confirm it passes, then commit.
- Run `.venv/Scripts/python -m pytest -q` and
  `.venv/Scripts/python -m ruff check src tests scripts` after every task; both must
  stay green/clean before moving to the next task.
- Conventional Commits (`feat:`, `test:`, `docs:`, `refactor:`), no AI attribution, no
  emojis, no pull request.
- All new `PurchaseOrder`/`LineItem` fields get default values so existing positional
  constructor calls in `tests/test_store.py` and `tests/test_municipal.py` keep working
  unmodified.

from osint_mercado import schema
from osint_mercado.models import PurchaseOrder


def is_cancelled(order: PurchaseOrder) -> bool:
    return order.codigo_estado == schema.ESTADO_CANCELADA


def drop_cancelled(orders: list[PurchaseOrder]) -> list[PurchaseOrder]:
    return [o for o in orders if not is_cancelled(o)]
